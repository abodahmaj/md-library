# مرحباً بك في مكتبة المستندات 📚

هذه المنصة مخصصة لمشاركة ملفات المارك داون التعليمية والتقارير بروابط مباشرة وخفيفة تناسب التصفح من الجوال والحاسوب.

---

## المميزات الأساسية

1. **دعم كامل للغة العربية (RTL)** والخطوط المريحة للعين.
2. **فتح فوري وسريع جداً** دون الحاجة لتطبيقات وسيطة.
3. **تنسيق متكامل** للجداول، الأكواد، والقوائم النقطية.
4. **نسخ الرابط بضغطة زر** لتسهيل الإرسال عبر واتساب أو تيليجرام.

---

### جدول توضيحي للمحتويات

| نوع المستند | الاستخدام | وسيلة المشاركة |
| :--- | :--- | :--- |
| ملخص سبوري | نافس والدروس اليومية | رابط ويب مباشر |
| خطط دراسية | تحضير واستراتيجيات | رابط ويب + تحميل |
| تقارير عامة | إحصائيات ونتائج | رابط دائم ومحدث |
