## 1. الأدوات الأساسية (Core Built-in Tools)

### terminal
- **الاسم:** terminal (الطرفية ومشغل الأوامر)
- **الوظيفة:** تنفيذ أوامر النظام وتطبيقات الطرفية داخل بيئة العمل.
- **الشرح:** تُستخدم لتشغيل أوامر Bash/Shell على الجهاز، وبناء المشاريع، وإدارة الحزم، والتحكم في العمليات الخلفية (Background processes).
- **مثال:** تشغيل خادم تطوير أو فحص حالة المستودع: `git status` أو `npm run dev`.
- **طريقة الاستخدام:**
  ```json
  {
    "command": "npm test",
    "background": false
  }
  ```

### read_file
- **الاسم:** read_file (قارئ الملفات)
- **الوظيفة:** قراءة محتويات الملفات النصية والبرمجية مع أرقام الأسطر.
- **الشرح:** تدعم قراءة الملفات المقسمة لأسطر وتجاوز الحجم الكبير، كما تدعم استخراج النصوص تلقائياً من ملفات PDF، الدفاتر البرمجية (.ipynb)، وملفات Office.
- **مثال:** قراءة أول 100 سطر من ملف الإعدادات `config.yaml`.
- **طريقة الاستخدام:**
  ```json
  {
    "path": "C:/Users/aboda/config.yaml",
    "offset": 1,
    "limit": 100
  }
  ```

### write_file
- **الاسم:** write_file (كاتب الملفات الكامل)
- **الوظيفة:** كتابة وإنشاء ملفات جديدة أو استبدال ملفات بالكامل.
- **الشرح:** تنشئ المجلدات تلقائياً إذا لم تكن موجودة، وتتحقق من صحة وصلاحية الكود لغوياً وتنسيقياً بعد الكتابة.
- **مثال:** كتابة ملف كود جديد أو إنشاء صفحة HTML كاملة.
- **طريقة الاستخدام:**
  ```json
  {
    "path": "C:/Users/aboda/Desktop/app.py",
    "content": "print('Hello Hermes')\n"
  }
  ```

### patch
- **الاسم:** patch (معدل النصوص الموجه)
- **الوظيفة:** استبدال مقطع محدد ودقيق داخل الملف دون إعادة كتابته كاملاً.
- **الشرح:** تعتمد على تقنيات المطابقة المرنة (Fuzzy matching) لتفادي مشاكل الفراغات البسيطة، وهي الطريقة المثلى والآمنة للتعديل على المشاريع القائمة.
- **مثال:** تحديث قيمة متغير أو استبدال دالة معينة.
- **طريقة الاستخدام:**
  ```json
  {
    "path": "C:/Users/aboda/Desktop/app.py",
    "old_string": "PORT = 3000",
    "new_string": "PORT = 8080"
  }
  ```

### search_files
- **الاسم:** search_files (محرك البحث في الملفات)
- **الوظيفة:** البحث السريع داخل النصوص أو البحث عن أسماء الملفات عبر المسارات.
- **الشرح:** مدعومة بمحرك ripgrep فائق السرعة، تعمل إما كـ grep للبحث في محتوى الملفات أو كـ find للبحث بأسماء الامتدادات والملفات.
- **مثال:** العثور على جميع الملفات ذات الامتداد `.tsx` التي تستدعي مكتبة معينة.
- **طريقة الاستخدام:**
  ```json
  {
    "pattern": "useAuth",
    "target": "content",
    "file_glob": "*.tsx"
  }
  ```

### web_search
- **الاسم:** web_search (محرك البحث على الويب)
- **الوظيفة:** إجراء استعلامات وبحث فوري عبر الإنترنت.
- **الشرح:** تعيد العناوين، والروابط، ووصفاً مختصراً للمصادر لجلب أحدث التوثيقات البرمجية والبيانات الحية.
- **مثال:** البحث عن أحدث إصدار لمكتبة معينة أو حل لخطأ تقني.
- **طريقة الاستخدام:**
  ```json
  {
    "query": "Next.js 16 App Router release notes",
    "limit": 5
  }
  ```

### web_extract
- **الاسم:** web_extract (مستخرج محتوى المواقع)
- **الوظيفة:** قراءة وتجريد محتوى أي صفحة ويب أو مستند PDF عبر الرابط مباشرة.
- **الشرح:** تحوّل الصفحة إلى نص مارك داون نقي وسريع دون تشغيل المتصفح الثقيل، مع الحفاظ على هيكل الجداول والقوائم والروابط.
- **مثال:** استخراج مقال تعليمي أو ورقة بحثية عبر رابط مباشر.
- **طريقة الاستخدام:**
  ```json
  {
    "urls": ["https://example.com/article"]
  }
  ```

### browser_exec
- **الاسم:** browser_exec (أتمتة المتصفح الحقيقي)
- **الوظيفة:** قيادة متصفح كروميوم حقيقي للتفاعل مع الواجهات المعقدة والتطبيقات.
- **الشرح:** تمكّن من الضغط على العناصر، تعبئة النماذج، تصفح التطبيقات التي تتطلب جافاسكريبت، وتنفيذ دوال DOM الحية.
- **مثال:** تسجيل الدخول أو استخراج بيانات من لوحة تحكم تفاعلية.
- **طريقة الاستخدام:**
  ```json
  {
    "code": "# Open site\nnew_tab('https://example.com')\nwait_for_load()\nprint(page_info())"
  }
  ```

### vision_analyze
- **الاسم:** vision_analyze (محلل الصور والرسومات)
- **الوظيفة:** تحليل الصور الملتقطة والرسوم البيانية وتفحص التفاصيل المرئية.
- **الشرح:** تسمح باستيعاب الصور وفحص الأخطاء التخطيطية أو قراءة النصوص من الصور بدقة متناهية عبر تحديد إحداثيات محددة إذا لزم الأمر.
- **مثال:** فحص تصميم واجهة أو استخراج نصوص من صورة مرسلة.
- **طريقة الاستخدام:**
  ```json
  {
    "image_url": "C:/Users/aboda/Desktop/screenshot.png",
    "question": "ما هو نص الخطأ الظاهر في مربع الحوار؟"
  }
  ```

## 2. أدوات ومحركات إدارة المهام والذاكرة (Task & Memory Management)

### memory
- **الاسم:** memory (الذاكرة الدائمة عبر الجلسات)
- **الوظيفة:** حفظ واسترجاع الحقائق والبيانات الثابتة التي يجب تذكرها دائماً.
- **الشرح:** تحتفظ بتفضيلات المستخدم، معلومات النظام، والمسارات المهمة لضمان استمراريتها في جميع الجلسات القادمة.
- **مثال:** تسجيل تفضيل المستخدم في تنسيق التقارير أو معلومات الاتصال.
- **طريقة الاستخدام:**
  ```json
  {
    "target": "memory",
    "action": "add",
    "content": "User prefers concise summaries."
  }
  ```

### delegate_task
- **الاسم:** delegate_task (تفويض الوكلاء الفرعيين)
- **الوظيفة:** تشغيل وكلاء أذكياء فرعيين ومستقلين لمعالجة مهام موازية أو معقدة.
- **الشرح:** يعزل المهام التي تتطلب بحثاً مكثفاً أو خطوات برمجية طويلة حتى لا تستهلك سياق المحادثة الرئيسي، ثم يعيد النتيجة النهائية ملخصة.
- **مثال:** تشغيل وكيل يبحث في بنك الأسئلة وآخر يجهز الرسوم التوضيحية في نفس الوقت.
- **طريقة الاستخدام:**
  ```json
  {
    "tasks": [
      {"goal": "Search repository for database models and return diagram"}
    ]
  }
  ```

### clarify
- **الاسم:** clarify (طرح الأسئلة التوضيحية التفاعلية)
- **الوظيفة:** استيضاح خيارات أو تفضيلات من المستخدم عبر بطاقات تفاعلية.
- **الشرح:** تعرض خيارات قابلة للنقر مع التوصية بالخيار الأنسب لتحديد اتجاه التنفيذ بدقة.
- **مثال:** سؤال المستخدم عن المنصة المفضلة لنشر المستند قبل البدء.
- **طريقة الاستخدام:**
  ```json
  {
    "questions": [
      {
        "question": "ما هي التقنية التي تفضلها للواجهة؟",
        "choices": ["Next.js", "Static HTML", "Vue"]
      }
    ]
  }
  ```

### kanban (مجموعة أدوات الكانبان)
- **الاسم:** kanban (إدارة المشاريع بالبطاقات)
- **الوظيفة:** تتبع سير العمل، إنشاء المهام الفرعية، وربط التبعيات بين المهام.
- **الشرح:** تضم أدوات مثل `kanban_create` و `kanban_list` و `kanban_complete` لتنسيق المشاريع المتعددة الخطوات ومتابعة الإنجاز بدقة.
- **مثال:** إنشاء بطاقة عمل مخصصة لمراجعة كود أو إضافة ميزة.

## 3. مهارات التطوير والبرمجة (Development & Engineering Skills)

### tabee3-next16-arabic-app
- **الاسم:** tabee3-next16-arabic-app (تطوير تطبيق تابع / alimo-web)
- **الوظيفة:** إدارة وتطوير المشروع الرئيسي للمستخدم المبني على Next.js 16 مع SQLite.
- **الشرح:** تضمن تطبيق أفضل الممارسات لدعم اللغة العربية (RTL)، إدارة الجلسات، ومعالجة البيانات دون تسريب أو أخطاء برمجية.
- **مثال:** إضافة نموذج جديد لإدخال درجات الطلاب أو تعديل الشريط الجانبي.
- **طريقة الاستخدام:** استدعاء المهارة عبر `skill_view(name='tabee3-next16-arabic-app')`.

### github-pr-workflow & github-issues
- **الاسم:** GitHub Automation Suite
- **الوظيفة:** إدارة كامل دورة حياة المستودعات، طلبات السحب (PRs)، والتذاكر (Issues).
- **الشرح:** تتيح إنشاء الفروع، رفع التعديلات، عمل مراجعة برمجية ذاتية، وفحص خطوط الإنتاج والـ CI/CD عبر أداة `gh`.
- **مثال:** فتح Pull Request تلقائي بعد إنهاء ميزة واختبارها.
- **طريقة الاستخدام:** تنفيذ المهام عبر مهارات `github-pr-workflow` المخصصة.

### express-sqlite-backend & vue-sqlite-hybrid-apps
- **الاسم:** SQLite Hybrid Architectures
- **الوظيفة:** بناء تطبيقات الويب الهجينة وربط خوادم Express مع قواعد بيانات SQLite المحلية.
- **الشرح:** تركز على بناء واجهات برمجية خفيفة وسريعة (CRUD) للأدوات الداخلية أو الأنظمة المكتبية المحلية.
- **مثال:** إنشاء خادم مصغر لتخزين نتائج مسابقة أو استبيان مدرسي.

## 4. مهارات المستندات والتقارير والتعليم (Documents, Reports & Education)

### summary-spouri
- **الاسم:** summary-spouri (الملخص السبوري التعليمي - نافس)
- **الوظيفة:** إعداد ملخصات سبورية متكاملة وفق المعايير الرسمية (الهيكل الإلزامي ذو الـ 8 بنود).
- **الشرح:** يبني الملخص شاملاً: تهيئة نافس، الأهداف الكاملة 🎯، الأهمية، المفردات، عناصر الدرس، ماذا قرأت، اختبر نفسك، وقسم نافس التحليلي مع التذييل المعتمد.
- **مثال:** إعداد ملخص درس العلوم للصف الثاني المتوسط مع ربط أرقام الأشكال بدقة.
- **طريقة الاستخدام:** تفعيل المهارة عند طلب تحضير أو تلخيص درس دراسي.

### moe-textbook-converter
- **الاسم:** moe-textbook-converter (محول مناهج وزارة التعليم)
- **الوظيفة:** استخراج وتحويل كتب المناهج الدراسية إلى ملفات Word و Markdown نظيفة.
- **الشرح:** تُعد الخطوة الأساسية الأولى لاستخراج نصوص الكتب والجداول بدقة تامة والاعتماد عليها كمصدر حصري للدروس دون تأليف أو نقص.
- **مثال:** تحويل وحدة المادة والطاقة من كتاب العلوم إلى مستند قابل للبحث.

### arabic-pdf-reports & pdf-master-assistant
- **الاسم:** Arabic Document Engineering
- **الوظيفة:** معالجة، قراءة، وتوليد تقارير الـ PDF باللغة العربية بدقة هندسية.
- **الشرح:** تضمن ضبط اتجاه النصوص، عدم انعكاس الحروف العربية، ودعم تنسيق جداول الطباعة مقاس A4 عبر مكتبات متخصصة مثل fpdf2 و PyMuPDF.
- **مثال:** طباعة كشوفات المتابعة أو تقارير الدرجات بتنسيق جاهز للطباعة مباشرة.

### document-shipping
- **الاسم:** document-shipping (نشر وتصدير المستندات)
- **الوظيفة:** مشاركة المستندات السريعة وتوليد روابط خارجية للمعاينة وإرسالها عبر تيليجرام.
- **الشرح:** ترفع الملفات وتحولها لروابط مباشرة وترسل التنبيهات إلى قنوات أو مجموعات التليجرام المعتمدة للمستخدم.
- **مثال:** إرسال تقرير جاهز إلى مجموعة My_Saves على تيليجرام.

## 5. مهارات إدارة العمليات والتنسيق الفائق (Superpowers & Orchestration)

### superpowers:brainstorming
- **الاسم:** brainstorming (العصف الذهني والاستكشاف المنهجي)
- **الوظيفة:** استكشاف المتطلبات ومقارنة الحلول التقنية قبل كتابة أي كود.
- **الشرح:** تمنع التسرع في التنفيذ الخاطئ عبر طرح البدائل، دراسة المخاطر، والوصول إلى أفضل هيكلية للمشروع بالتعاون مع المستخدم.
- **مثال:** مقارنة خيارات استضافة المستندات (Notion مقابل GitHub Pages).

### superpowers:writing-plans & executing-plans
- **الاسم:** Systematic Planning & Execution
- **الوظيفة:** كتابة خطط برمجية تفصيلية خطوة بخطوة ثم تنفيذها بدقة والتحقق من كل خطوة.
- **الشرح:** تحوّل الأفكار المعقدة إلى مهام صغيرة محددة وقابلة للقياس والاختبار، مع تقديم دلائل تنفيذ واقعية (Execution evidence).
- **مثال:** بناء ميزة جديدة في المنصة تبدأ من قاعدة البيانات وتنتهي بالواجهة.

### superpowers:systematic-debugging
- **الاسم:** systematic-debugging (استكشاف الأخطاء الجذري)
- **الوظيفة:** تشخيص المشاكل والعلل البرمجية وفق منهجية من 4 مراحل.
- **الشرح:** فهم المشكلة -> إعادة إنتاجها -> عزل السبب الجذري -> الحل والتحقق، وتمنع الحلول العشوائية أو التخمين.
- **مثال:** حل مشكلة فشل بناء المشروع أو تعارض الحزم.

## 6. أدوات وخوادم التكامل الخارجي (MCP & External Connectors)

- **Notion MCP:** إدارة صفحات وقواعد بيانات نوشن برمجياً وإنشاء المستندات وقراءتها.
- **Canva MCP:** توليد وتعديل التصاميم، الصور، والبطاقات الرسومية عبر واجهات كانفا.
- **Supabase MCP:** إدارة قواعد بيانات Postgres السحابية، تنفيذ الاستعلامات، وتحديث الهيكليات.
- **Vercel & Netlify MCPs:** إدارة عمليات النشر والاستضافة وتتبع صحة التطبيقات السحابية.
- **Home Assistant & Spotify:** التحكم في الأجهزة الذكية وتشغيل الوسائط عبر بروتوكولات الاتصال المباشرة.
